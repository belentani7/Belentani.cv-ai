     1→# Manos Abiertas - Worklog
     2→
     3→## Project Overview
     4→**Manos Abiertas** is a comprehensive multilingual platform for immigrants in Spain.
     5→- Main focus: AI education (GPT, Gemini, Qwen, Copilot, DeepSeek) + CV builder
     6→- 35+ languages support (Spanish, Catalan, Portuguese-BR, Chinese, Hindi, Quechua, etc.)
     7→- Resources directory (3000+ links from government, GitHub, NGOs)
     8→- Survival guide (rights, aid, emergency contacts)
     9→- Office Pack complete course
    10→- Target audience: immigrants with low tech literacy (mostly Google + WhatsApp users)
    11→
    12→## Architecture
    13→- Single-page app with tab/section navigation (user can only see `/`)
    14→- Zustand for state (language, UI, CV data)
    15→- Tailwind 4 + shadcn/ui (New York)
    16→- Prisma + SQLite for resources, courses, CVs
    17→- z-ai-web-dev-sdk (LLM) for CV generation
    18→- Framer Motion animations
    19→- next-themes for dark/light mode
    20→
    21→## Sections (tabs)
    22→1. Inicio (Home) - Hero, mission, quick access, language selector
    23→2. Aprende IA - AI courses (GPT, Gemini, Qwen, Copilot, DeepSeek)
    24→3. Crea tu CV - AI-powered CV builder
    25→4. Office Pack - Word/Excel/PowerPoint course
    26→5. Recursos - 3000+ links directory (searchable)
    27→6. Derechos y Ayudas - Rights, aid, survival guide
    28→7. Contactos - Emergency contacts, NGOs
    29→
    30→## Tech Stack
    31→- Next.js 16 App Router + TypeScript 5
    32→- Tailwind CSS 4 + shadcn/ui
    33→- Prisma ORM (SQLite)
    34→- Zustand + TanStack Query
    35→- Framer Motion
    36→- z-ai-web-dev-sdk (backend only)
