## 1) Winget “forense” y actualizado en Windows 11

Ejecuta en **PowerShell** o **Windows Terminal**:

```powershell
# Ver winget y fuente
winget --version
winget source update

# Actualizar todo lo instalable con winget
winget upgrade --all --accept-source-agreements --accept-package-agreements

# Listar software instalado
winget list --accept-source-agreements | Out-File "$HOME\Desktop\winget-list.txt"

# Exportar paquetes instalados para auditoría / reproducibilidad
winget export -o "$HOME\Desktop\winget-packages.json"

# Importar en otro equipo
# winget import -i "$HOME\Desktop\winget-packages.json"
```

### Buscar paquetes actualizados

```powershell
winget search "web development" --source winget
winget search --id Node --source winget
winget search --id Python.Python --source winget
winget search --id Tailwind --source winget
winget search --id Docker --source winget

winget show --id OpenJS.NodeJS.LTS --versions
winget show --id Microsoft.VisualStudioCode --versions
```

### Auditoría rápida de herramientas de desarrollo instaladas

```powershell
Get-Command node,npm,pnpm,yarn,bun,deno,python,pip,git,code,docker,kubectl,terraform,ffmpeg,magick -ErrorAction SilentlyContinue |
  Format-Table Name,Source,Version -AutoSize
```

```powershell
npm ls -g --depth=0
```

### Búsqueda “forense” de proyectos web en tu usuario

```powershell
Get-ChildItem -Path $env:USERPROFILE -Recurse -File -Include `
  package.json,index.html,astro.config.*,next.config.*,nuxt.config.*,vite.config.*,`
  tailwind.config.*,postcss.config.*,*.sln,*.code-workspace -ErrorAction SilentlyContinue |
  Select-Object FullName,LastWriteTime |
  Sort-Object LastWriteTime -Descending |
  Format-Table -AutoSize
```

> Puede tardar. Si quieres búsqueda de archivos ultra rápida en Windows 11, instala **Everything**:
>
> ```powershell
> winget install --id voidtools.Everything -e
> ```

## 2) Script winget para instalar máximo stack web en Windows 11

Pega esto en PowerShell si quieres una función reusable:

```powershell
function Install-WingetIds([string[]]$Ids) {
  foreach ($id in $Ids) {
    Write-Host "`nInstalando: $id" -ForegroundColor Cyan
    winget install --id $id --exact --silent --accept-package-agreements --accept-source-agreements
    if ($LASTEXITCODE -ne 0) {
      Write-Warning "No se pudo instalar $id. Revisa con: winget search $id"
    }
  }
}
```

Después instala por bloques:

## 8) Prompt/Codex listo para usar con GPT o Codex

Copia esto como contexto/instrucción:

```text
Actúa como un experto en desarrollo web moderno, diseño UI, rendimiento, accesibilidad y SEO técnico.

Objetivo:
Ayudar a crear páginas web modernas, visuales, rápidas, responsive, accesibles y listas para producción en Windows 11.

Reglas:
1. Prioriza herramientas gratuitas u open source.
2. Si propones software instalable en Windows, usa comandos winget con IDs exactos cuando sea posible.
3. Antes de instalar, verifica si el paquete existe con:
   winget search <nombre>
   winget show --id <ID> --versions
4. No ejecutes instalaciones sin confirmación explícita del usuario.
5. Para recursos visuales, usa sitios gratuitos y verifica licencias antes de uso comercial.
6. Para frontend, recomienda stacks modernos según necesidad:
   - Landing simple: HTML + CSS + JS o Astro.
   - App web: Next.js, Nuxt, SvelteKit o Vite + React.
   - Docs: VitePress, Docusaurus o MkDocs.
   - Portfolio: Astro o Next.js.
7. Para diseño, prioriza:
   - Tailwind CSS, shadcn/ui, DaisyUI, Flowbite, Mantine, Chakra UI o Bootstrap.
   - Iconos: Lucide, Tabler, Heroicons, Phosphor, Remix Icon, SVGRepo.
   - Imágenes: Unsplash, Pexels, Pixabay.
   - Ilustraciones: unDraw, Storyset, Open Peeps, Humaaans.
   - Animaciones: LottieFiles, GSAP, Motion, Rive, Animista.
8. Entrega siempre:
   - Comandos winget necesarios.
   - Comandos npm/pnpm necesarios.
   - Extensiones VS Code recomendadas.
   - Recursos visuales gratuitos.
   - Checklist de calidad: responsive, accesibilidad, SEO, rendimiento, favicon, PWA, deploy.
9. Si el usuario pide “búsqueda forense” en Windows 11:
   - Usa winget list, winget export, Get-Command, Get-ChildItem.
   - Busca proyectos por package.json, index.html, vite.config.*, next.config.*, astro.config.*.
   - No borres nada sin confirmación.
10. Si falta una herramienta, propón instalación con winget, npm, pnpm, corepack o WSL2.

Formato de respuesta deseado:
A. Diagnóstico.
B. Herramientas instaladas/faltantes.
C. Comandos winget.
D. Comandos npm/proyecto.
E. Recursos visuales free.
F. Checklist final.
```
